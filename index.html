Souveraineté

Vos données industrielles restent en Europe

Vos données d'audit sont stockées en France : VPS Scaleway (Iliad group, Paris) pour l'application Energy, base Supabase Paris pour toutes les données d'inventaire et les photos. Le traitement IA principal utilise Mistral (souveraineté EU). Les briques OCR et transcription vocale s'appuient aujourd'hui sur Google Cloud Europe, avec une migration vers un stack 100% souverain planifiée pour la version 2.0.
